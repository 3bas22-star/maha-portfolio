# معرض أعمال مها 🤍

صفحة واحدة تعرض أعمالي في تصميم وتطوير صفحات الويب والذكاء الاصطناعي، كل عمل في بطاقة فيها صورة وعنوان وسطر نتيجة.

## الأعمال
1. موقعي الشخصي
2. صفحة تعريفية بالذكاء الاصطناعي
3. دليل كتابة الأوامر (Prompts)

## الملفات
- `index.html`: الصفحة الرئيسية
- `style.css`: التنسيق (ألوان نود وخط Cairo)
- الصور بصيغة WebP (كل صورة أقل من 200 كيلوبايت): personal-site.webp و ai-intro.webp و prompt-guide.webp

## النشر
الموقع منشور على Cloudflare Pages، وكل تعديل يُرفع للمستودع يُنشر تلقائيًا.

---
المشروع الثاني في مقرر **بناء ونشر المواقع بالذكاء الاصطناعي** (الدرس 4).
